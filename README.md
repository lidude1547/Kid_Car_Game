# 小小賽車手 3D

給 2–6 歲小朋友玩的 3D 賽車遊戲，手機、平板、電腦都能玩（手機請橫著拿）。

- 24 站 F1 賽道（簡化輪廓、真實長度），白天／夕陽／夜間場景
- 7 種車型、6 個汽車品牌、6 個車隊塗裝、13 種顏色
- 時間可選依賽道／白天／黃昏／夜晚，天氣可選晴天／雨天／雪天（雨雪路滑）
- 每個汽車品牌車身造型不同（車頂、車鼻、輪拱、尾翼、進氣口），車隊彩繪會依車色變成鮮豔對比配色
- 自己轉方向盤、自己踩油門，最高 350 km/h，方向盤靈敏度 1–5
- 9 台車同場，前三名上頒獎台
- **👥 連線對戰**：開房間時選 2／3／4 人，拿到 4 位數房號，朋友輸入房號加入；人到齊、而且每個人都按「開始比賽」顯示 READY 後，倒數 3 秒自動開賽（空位由電腦補滿 9 台）。開房間需要開房密碼，房間名稱由房主自己取。每個房間有一組 4 位數房間密碼（只有房主看得到，要由房主告訴朋友）；朋友在清單點房間、輸入密碼才能加入。房主離開後房間會自動從清單消失。
- 比賽中：畫面上方的進度條、小地圖彩色圓點、朋友車上的名牌，隨時知道朋友跑到哪裡
- 房主按「下一站」或「再玩一次」，朋友會收到提示：請按下一站並按 READY

- 操控：左下角 360° 圓形搖桿（左右轉彎、往上加速、往下煞車），右下角油門／煞車鍵；隨時可按 🏠 回主頁

## 怎麼玩

打開 GitHub Pages 網址即可，不需要安裝或登入。

**全螢幕玩（沒有網址列）**
- iPhone / iPad：用 Safari 打開 → 分享 ⬆️ →「加入主畫面」，之後從主畫面圖示打開。
- Android：Chrome 會出現「安裝到主畫面」，或比賽開始時自動全螢幕。
- 在 LINE 裡點連結會自動改用手機的瀏覽器打開。

**語音聊天**：連線時點「🎤 麥克風：關」打開麥克風（再點一下關掉），朋友就聽得到你說話；只有在說話時才會傳送聲音。

**邀請朋友**：房主在大廳按「📋 複製邀請連結」傳給朋友，朋友點連結後只要輸入房主告訴他的密碼。

## 連線說明

連線透過免費的公開 MQTT 轉送伺服器（broker.emqx.io，連不上時自動改用 HiveMQ／Mosquitto），走一般的安全網頁連線，手機網路、家用 Wi-Fi 都能用。房主切到其他 App（例如用 LINE 傳房號）時房間會保留，回來後會收到這段時間的加入請求。
