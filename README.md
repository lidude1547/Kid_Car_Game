# 小小賽車手 3D

給 2–6 歲小朋友玩的 3D 賽車遊戲，手機、平板、電腦都能玩（手機請橫著拿）。

- 24 站 F1 賽道（簡化輪廓、真實長度），白天／夕陽／夜間場景
- 7 種車型、6 個汽車品牌、6 個車隊塗裝、13 種顏色
- 自己轉方向盤、自己踩油門，最高 350 km/h，方向盤靈敏度 1–5
- 9 台車同場，前三名上頒獎台
- **👥 連線對戰**：開房間拿到 4 位數房號，朋友輸入房號就能一起跑（最多 4 人，空位由電腦補滿）

## 怎麼玩

打開 GitHub Pages 網址即可，不需要安裝或登入。

## 連線說明

連線使用 [PeerJS](https://peerjs.com/) 的免費公開配對服務，玩家之間直接點對點傳送車子位置。少數網路（公司網路、部分行動網路）可能會擋點對點連線，連不上時換個網路（例如家裡 Wi-Fi）試試。
